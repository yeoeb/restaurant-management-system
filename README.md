# 🍽️ Restaurant Management System

A web-based restaurant ordering and management system developed using PHP and MySQL.

## Features

- User Login / Logout
- User Management
- Menu Management (CRUD)
- Shopping Cart
- Order Submission
- Current Orders
- Order History

## Tech Stack

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## Database

- Users
- Menu
- Orders
- Order Items

## Installation

1. Import the SQL file into MySQL.
2. Modify the database configuration.
3. Start Apache and MySQL.
4. Open the project in your browser.
